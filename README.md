# IT_Salary_PCA

Использование метода главных компонент (PCA) для определения основных
параметров, определяющих заработок ИТ-специалиста.

Данные: Stack Overflow Developer Survey 2025 (лицензия ODbL),
data/raw/so_survey_2025.csv, версионируется через DVC.

Окружение:
    uv venv --python 3.12 .venv
    uv pip install -r requirements.txt
    dvc pull
